# 2026-11-13 이벤트 기반 AI 호출 수정

오늘 작업 집계: paper_opportunity 61건(완료 57, 실패 4), paper_management 3건. 기회 요청 61건 모두 reference_reaction을 포함했고 wave_structure 34건, divergence 11건, swing_breakout 5건이었다. 서로 중복된 분류이므로 합산하지 않는다.

기존 문제: 작은 기준선 반응과 새 파동 후보가 매번 호출 후보가 되고, 동일 후보도 1시간 후 재호출 가능했다. 보유 포지션은 새 변화 없이 매시간 재평가했다.

수정: 15초 가격 스캔에서 AI 없는 이벤트 감지. 작은 기준선/파동/다이버전스는 최근 1시간 박스 경계(5분 ATR 0.25 이내)에서, 마지막 검토 대비 max(5분 ATR 0.75, 가격 0.25%) 이동한 경우만 호출 후보. 기존 변위/스윙 돌파 감지도 유지. 같은 일반 이벤트는 24시간 중복 억제. 시간만 지난 포지션 재평가 제거.

급변: 1분봉 시작 가격과 현재 가격으로 5분 2%, 15분 3%, 60분 4% 감지. 마지막 검토 이후 누적 2% 이동도 감지. 활성 계획 진입/확인/무효화/손절/익절선 통과 감지. 계획선 통과는 대기·쿨다운 중 최대 15분 보존. 급변 반복은 5분 최소 간격 및 추가 1% 가격 이동으로 제한.

일반 하루 64회는 유지하며 급변 전용 추가 8회, 전문팀 추가 24회 여유. 일반 후보는 이 여유를 사용할 수 없다. 실제 계정 한도와 별개이며 전용 여유까지 사용하면 다음 KST 자정까지 해당 자동 AI 검토도 제한된다. 주문·손절·익절 실행 규칙은 변경하지 않았다.

로컬 290개, VPS 287개 테스트 통과. 테스트의 model-not-supported 로그는 모의 실패 검증 출력이다.
