## 검토와 실제 적용

`book-rules.json`에 출처가 있는 핵심 규칙 29개를 정리했다. 임펄스의 기본 제약, 차수와 내부 구조, ABC/WXY/삼각형/다이아고날 구분, 닐리의 추가 조건과 사후 확인, 구조적 무효화와 거래 손절의 구분을 다룬다. 하모닉은 엘리어트 판단을 대체하지 않는 보조 자료다.

검토는 기본 노트, 임펄스·조정파·복합조정·사후 확인 장과 거래 사례의 핵심 규칙에 집중했다. 영문 닐리 PDF 64–67, 71, 73–75, 80, 85–87, 97, 99–101, 112–113쪽; 개정판 240–245, 267–268, 311, 313–315쪽; Balan 문단 178–225, 240–251, 280–318, 690–725; Visual Guide 문단 1024–1065 등의 주요 규칙을 대조했다. 전체 페이지와 모든 도표를 수작업으로 검토한 상태는 아니다.

실행 시 1일→4시간→1시간→15분 자료에 맞는 검토된 규칙만 제한된 크기로 AI 입력에 넣는다. 전체 책을 매번 보내지 않는다. AI가 선택한 규칙 ID가 실제 입력에 있었는지 검증하고, 메시지에는 적용 설명과 코드가 생성한 출처를 접힌 인용구에 표시한다.

최근 여섯 피벗을 0–5로 가정한 일반 임펄스 가격 검사도 추가했다. 2파의 시작점 침범, 4파 겹침, 완성된 피벗에서 3파 최단 여부 등을 확인한다. 미완성 5파를 완성으로 취급하지 않으며, 분석 시점 이후 확인된 피벗을 허용하지 않는다. 이것은 가정한 여섯 끝점의 검사이며 전체 차트의 파동 판정이나 다이아고날 검증이 아니다.

## 충돌·오류 처리

- 기초 자료의 삼각형 내부 구조 표기가 앞뒤로 충돌한다. 해당 도표를 직접 확인했고, 잘못된 표기를 자동 규칙으로 쓰지 않는다.
- 일반 엘리어트와 닐리의 플랫·교대·연장 조건은 체계를 구분한다. 서로 다른 기준을 하나의 필수 조건으로 섞지 않는다.
- 특정 되돌림 비율, 채널 이탈, 저자의 빈도 설명을 확정 신호나 BTC/ETH의 실측 승률로 바꾸지 않는다.
- 번역/OCR의 숫자·단위 오류 가능성이 있는 문장은 별도 확인 없이 강제 조건으로 쓰지 않는다. DOCX 미리보기의 한글 글꼴 누락은 XML 원문과 원본 삽입 도표로 보완했다.

## 아직 완료하지 않은 범위

전체 자료의 도표별 정독, 닐리 모노파동 구성·압축·시간/가격 비례 전 규칙의 자동 구현, 모든 복합 패턴의 결정론적 판별은 완료하지 않았다. ATR 피벗을 닐리 모노파동과 동일하다고 간주하지 않는다. 내부 세분화·동일 차수·구간 중간 극값·사후 확인은 별도 검증 항목이다.

이 작업은 모델 자체를 재학습한 것이 아니라 원문 검색 자료와 검토된 분석 규칙을 만든 것이다. 예측 정확도 향상을 입증한 백테스트는 아직 없다. 향후 평가는 미래 데이터 누출을 차단한 시점별 재생, 기간 분리, 거래 비용, 오탐·미탐, 손익비 및 최대 손실을 함께 확인해야 한다. 현재 시나리오 가중치는 실측 승률이 아닌 분석상 상대 가중치다.

## 배포 확인

VPS의 분리된 테스트 경로에서 기존 기능을 포함한 76개 테스트를 통과했다. 운영 코드·규칙 파일의 SHA-256 일치를 확인했고, 두 서비스의 재시작 후 active 상태를 확인했다. 운영 BTC/ETH 스냅샷 모두에서 네 시간대의 가격 검사와 규칙 선택이 실행되고, 최종 AI 입력에도 보존되는 것을 확인했다. 이번 확인을 위해 별도 유료 모델 호출이나 텔레그램 시험 발송은 하지 않았다. 따라서 새 규칙이 포함된 실제 AI 응답과 텔레그램 수신까지 확인한 상태는 아니다.
