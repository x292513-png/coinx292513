# 공통 진입 경로와 가격 근거

사용자 지침: 전체 ABC 종료와 큰 W 종료 후 X 반등처럼 파동 해석이 달라도, 동일한 지지와 확인 조건에서 공통으로 매수 가능한 구간을 설명한다. 진입 가격만 나열하지 않고 가격대의 중첩 근거, 확인 조건, 실패 조건 및 후보별 청산 차이를 함께 제시한다.

## 구현
- entry_logic: shared_path, supporting_scenarios(최대3; 각 진입 근거 및 청산/홀딩 차이), confluence, trigger, failure_case, measurement_ids.
- 후보 개수를 확률로 환산하지 않는다. 연관된 FVG/OB/파동 피벗도 독립 증거로 더하지 않는다.
- snapshot에 확정봉 SMA100/200과 기점이 명시된 0.382/0.5/0.618/0.786 되돌림 후보를 공급한다. 일봉은 최근 스윙 외 제공된 피벗 중 최고점까지의 상승도 비교한다. 피보나치 기준 스윙은 구조 확정 판정이 아니며 모델이 차수 선택 이유를 설명해야 한다.
- 측정값 ID를 출력 스키마의 enum으로 제한하고 반환 시 실제 입력 ID와 다시 대조한다. 근거 없이 200일선이나 0.618 접촉을 만들어낼 수 없도록 지시한다. SMA/EMA 구분, 접촉과 반전 확인 구분.
- 전체 분석·정기 브리핑에 공통 진입 근거와 펼침 상세 표시. 자유 질문에도 같은 판단 원칙 적용.
- 기존 보고서는 신규 필드 없이도 표시 가능.
